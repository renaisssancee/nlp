## Описание проекта

**CineMatch** — система рекомендаций фильмов на основе RAG (Retrieval-Augmented Generation).
Пользователь описывает на русском или английском языке, что хочет посмотреть, а система находит подходящие фильмы из базы TMDB 5000 и объясняет, почему каждый фильм подходит.

## Обоснование выбора темы

Существующие сервисы (Кинопоиск, Netflix, IMDb) не понимают свободный текст вида «что-то душевное на выходные» или «как Интерстеллар, но короче 2 часов». RAG позволяет совместить точный векторный поиск по семантике с гибкой генерацией ответа от LLM.

## Архитектурные решения

| Решение | Обоснование |
|---------|-------------|
| ChromaDB как векторная БД | Локальная, персистентная, не требует отдельного сервера, легко встраивается в Python |
| sentence-transformers (`all-MiniLM-L6-v2`) | Бесплатная модель, 384-мерные векторы, хорошо работает на английских текстах |
| Cross-encoder для реранкинга | Повышает точность топ-5 без большого overhead |
| OpenRouter (free tier) | Несколько бесплатных моделей с fallback-цепочкой — надёжнее, чем один провайдер |
| Streamlit для UI | Быстрый прототип без frontend-разработки |
